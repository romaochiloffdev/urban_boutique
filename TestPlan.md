# Black-Box Testing Plan
**Author:** Ochilov Ilyosjon (ID: B2300540)
**Project:** Urban Style POS System

This document outlines the Black-Box Testing Plan for the Urban Style POS System, ensuring that all functional requirements specified in the Program Specification are met without requiring knowledge of the internal code structure.

| Test ID | Feature / Module | Description (What is being tested?) | Steps to Execute | Expected Outcome | Pass / Fail |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **TC-001** | User Authentication (Login) | Verify that a user with valid credentials can log in successfully. | 1. Open the Login window.<br>2. Enter a valid Admin username.<br>3. Enter the correct password.<br>4. Click the "LOGIN" button. | The system authenticates the user and opens the correct dashboard (Admin Dashboard). | [ ] |
| **TC-002** | User Authentication (Login) | Verify that the system rejects invalid credentials. | 1. Open the Login window.<br>2. Enter a random/invalid username.<br>3. Enter any password.<br>4. Click "LOGIN". | An error message "Invalid username or password" is displayed. The user remains on the login screen. | [ ] |
| **TC-003** | User Management (Add User) | Ensure the Admin can add a new Sales Staff account. | 1. Log in as Admin.<br>2. Open "USER MANAGEMENT".<br>3. Fill in a new username, password, and select "Sales Staff" role.<br>4. Click "ADD NEW USER". | A success message is shown. The new user appears in the System Users DataGrid immediately. | [ ] |
| **TC-004** | User Management (Reset Password) | Ensure the Admin can reset an existing user's password. | 1. Open "USER MANAGEMENT".<br>2. Enter an existing username.<br>3. Enter a new password.<br>4. Click "RESET PASSWORD". | A success message is shown indicating the password has been reset. The user can log in with the new password. | [ ] |
| **TC-005** | Inventory Management (Add Product) | Verify that a new product and its variant (Size/Color) can be added to the inventory. | 1. Log in as Admin.<br>2. Fill in Product Name, Price, Category, Size, Color, and Stock Quantity.<br>3. Click "MAHSULOTNI SAQLASH". | A success message is displayed. The DataGrid refreshes, and the new item appears in the list. | [ ] |
| **TC-006** | Inventory Management (Low Stock Indicator) | Verify that items with less than 5 stock quantity are highlighted in red. | 1. Add a product with a Stock Quantity of 4 (or less).<br>2. Observe the product in the Inventory DataGrid. | The row containing the low-stock product is highlighted in red with bold text. | [ ] |
| **TC-007** | Cashier Module (Search Product) | Check if the search functionality filters products correctly. | 1. Open the Cashier window.<br>2. Type a part of an existing product's name in the search bar.<br>3. Click "Search". | The Available Products DataGrid is filtered to show only products matching the search query. | [ ] |
| **TC-008** | Cashier Module (Add to Cart) | Ensure a selected product can be added to the shopping cart. | 1. Select a product from the Available Products DataGrid.<br>2. Click "ADD TO CART". | The product appears in the Shopping Cart DataGrid with Quantity = 1. Total amount updates. | [ ] |
| **TC-009** | Cashier Module (Stock Limit Check) | Verify that the cashier cannot add more items to the cart than the available stock. | 1. Select a product with a stock of 2.<br>2. Click "ADD TO CART" 3 times. | The 3rd attempt triggers a "Not enough stock available!" warning message. Quantity remains at 2. | [ ] |
| **TC-010** | Cashier Module (Remove Item) | Check if an item can be removed from the shopping cart. | 1. Add an item to the cart.<br>2. Select the item in the Cart DataGrid.<br>3. Click "REMOVE SELECTED ITEM". | The item's quantity decreases by 1. If quantity reaches 0, it is removed from the cart entirely. Total updates. | [ ] |
| **TC-011** | Cashier Module (Checkout) | Ensure that completing a checkout successfully deducts stock and clears the cart. | 1. Add valid items to the cart.<br>2. Click "COMPLETE CHECKOUT". | A success message is shown. The cart clears. The available stock in the left DataGrid reflects the deduction. | [ ] |
| **TC-012** | Reporting (Today's Sales) | Verify that today's total sales sum is calculated correctly. | 1. Perform a successful checkout of $100 in the Cashier module.<br>2. Open Admin panel -> "HISOBOTLARNI KO'RISH". | The "Today's Total Sales" card correctly displays the updated sum (e.g., +$100 from previous total). | [ ] |
| **TC-013** | Reporting (Dead Stock) | Ensure products not sold in the last 30 days appear in the Dead Stock list. | 1. Add a brand new product to inventory (no sales yet).<br>2. Open Reports window. | The newly added product appears in the "Dead Stock" DataGrid. | [ ] |
